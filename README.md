# Code Flow - SaaS Pricing Page

Modern subscription pricing page for Code Flow, a fictional code learning platform.

## 🎨 Features
- 3 pricing tiers (Starter, Pro, Enterprise)
- Responsive design (mobile-friendly)
- Modern gradient UI with cyan accents
- Clean feature lists with checkmarks
- Interactive buttons

## 🛠 Tech Stack
- **HTML5** - Semantic markup
- **CSS3** - Flexbox, gradients, animations


## 🚀 Live Demo
https://code-flow-pricing.netlify.app/

## 💡 How to Use
1. Clone this repo
2. Open `index.html` in your browser
3. Done!

## 📝 Details
- Built with vanilla HTML/CSS
- No frameworks or dependencies
